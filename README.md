# SCTX → PNG / GLB → OBJ Web Converter

A browser-based converter for:

- `.sctx` → `.png`
- `.glb` → `.obj`

## SCTX

SCTX conversion uses the original Daniil-SV/SCTX-Converter compiled to WebAssembly.

## GLB

GLB conversion uses the Assimp WebAssembly package `libassimp`.

The GLB → OBJ export requests materials, so the generated package can contain:

- `.obj`
- `.mtl`
- extracted texture files

The conversion runs in the browser. The source model is not uploaded to a conversion server.

## Supported input

- Individual `.sctx`
- Individual `.glb`
- `.zip` containing `.sctx` and/or `.glb`

## Output

All converted files are downloaded together as a ZIP so OBJ, MTL and texture files stay together.

## Important

The GLB converter is loaded from the `libassimp` package through esm.sh. Therefore the first GLB conversion requires an Internet connection to load the converter.

The SCTX WebAssembly files are generated by GitHub Actions.
