# SCTX → PNG Web Converter

A simple browser-based SCTX to PNG converter.

- Select one or multiple `.sctx` files.
- Conversion runs locally in the browser.
- SCTX files are not uploaded to a server.
- Uses the original Daniil-SV/SCTX-Converter decoder compiled to WebAssembly.
- Uses texture-only mode (`-t`).
- Shows progress and conversion results.

The WebAssembly files are generated by GitHub Actions.

Source:
https://github.com/Daniil-SV/SCTX-Converter
